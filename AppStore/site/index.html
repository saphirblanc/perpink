Perpink Support

An iPhone and Mac app for chatting with your own, self-hosted Hermes Agent.

Getting started

Perpink provides no AI service of its own: it connects to a Hermes Agent instance that you run. You need:

  • a Hermes Agent instance with its API server enabled;
  • network access to that server from your device, for example through a private Tailscale network;
  • the API key of the Hermes profile you want to use.

Open Settings in Perpink, enter the server address (for example http://hermes.example.ts.net:8642), the profile name if it isn't the default one, and its key, then tap Test connection.

Something doesn't work?

  • Can't connect: check that your device can reach the server (is Tailscale on?) and that the address includes the port.
  • The key is refused: each profile only accepts its own API_SERVER_KEY; make sure the profile name and the key match.
  • Profile not found: named profiles require gateway.multiplex_profiles to be on in Hermes.
