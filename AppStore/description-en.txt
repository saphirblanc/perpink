Perpink is an iPhone and Mac app for chatting with Hermes Agent, the open-source AI agent you host yourself.

Perpink provides no AI service of its own: it connects to your own Hermes instance. You will need:
• a Hermes Agent instance with its API server enabled;
• network access to that server, for example through a private Tailscale network installed on the device;
• the API key of the Hermes profile to use, entered in Settings.

Features
• Conversations with your agent, with formatted answers (headings, lists, tables, code)
• Photos and files attached to messages
• Conversation history loaded from the server, on iPhone and Mac alike
• Approval of the actions your agent asks to run
• Adjustable text size
